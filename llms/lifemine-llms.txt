# LifeMine

> LifeMine is a clinical-stage biopharmaceutical company pioneering Top-Down Drug Discovery — mining the fungal biosphere for genetically encoded small molecules and developing them into precision medicines for immune-mediated disease and organ transplant rejection. Founded 2017 by Gregory Verdine, Richard Klausner and WeiQing Zhou; headquartered in Watertown, Massachusetts, with sites in Gloucester, Massachusetts and Basel, Switzerland.

LifeMine publishes no developer portal, no API documentation and no llms.txt of its own. This file
was GENERATED by API Evangelist on 2026-08-04 from artifacts fetched from LifeMine's live hosts.
The company nonetheless operates two genuinely public, anonymous, machine-readable read APIs as a
byproduct of the platforms it runs — a WordPress REST API on its website, and a Greenhouse job
board API for its careers surface. Both are documented below.

## What is NOT here

LifeMine's drug-discovery platform (Avatar-Rx), its genomics, its compound libraries and its
clinical data are NOT exposed through any public API. No endpoint on either host returns
scientific, clinical or regulatory data. Do not represent the APIs below as access to LifeMine's
research.

## APIs

- [LifeMine Website Content API (WordPress REST)](https://lifeminetx.com/wp-json/): Anonymous read API over site content — 24 news items (press releases, publications, in-the-news, thought leadership), 9 static pages, 117 media assets, and a `team` custom post type carrying 15 leadership, founder and board records. 203 registered routes across 10 namespaces. No credentials required for reads.
- [LifeMine Careers API (Greenhouse Job Board)](https://boards-api.greenhouse.io/v1/boards/lifeminetx): Anonymous read API over open roles, departments and offices. 2 open roles, 32 departments, 3 offices observed 2026-08-04. Includes GDPR data-compliance blocks and AI-disclosure fields per role.
- [WPGraphQL endpoint](https://lifeminetx.com/graphql): Live GraphQL endpoint (RootQuery confirmed). Public introspection is DISABLED, so no schema is available — do not assume a schema.

## Key operations

Content API — base `https://lifeminetx.com/wp-json`:

- `GET /wp/v2/posts` — news; filter with `categories`, `after`, `search`; always send `_fields`.
- `GET /wp/v2/categories` — the news taxonomy: press-releases (9), in-the-news (13), publications (1), expedition-academy (1).
- `GET /wp/v2/team` — leadership, founders and board as structured records.
- `GET /wp/v2/team_categories` — leadership (10), founders (3), board-of-directors (7); people hold multiple terms, so deduplicate by id.
- `GET /wp/v2/pages` — about, science, pipeline, culture-careers, contact, privacy-policy.
- `GET /wp/v2/search` — cross-resource typed search stubs.
- `GET /wp/v2/media` — 117 assets with `source_url` and `alt_text`.

Careers API — base `https://boards-api.greenhouse.io/v1/boards/lifeminetx`:

- `GET /jobs` — open roles; add `content=true` for full descriptions.
- `GET /jobs/{id}?questions=true` — one role with departments, offices and application questions.
- `GET /departments?render_as=tree` — hiring org hierarchy.
- `GET /offices` — Basel CH, Gloucester MA, Watertown MA.

## Conventions

- **Auth:** none for reads on either surface. The WordPress discovery document advertises `"authentication": []`. Writes need a WordPress credential that is not issued to the public and return `401 rest_forbidden`.
- **Pagination (content):** `page` / `per_page` (max 100) / `offset`; read `X-WP-Total` and `X-WP-TotalPages` headers; `Link: rel="next"` per RFC 8288. Both headers are CORS-exposed.
- **Pagination (careers):** none — collections return whole, with `meta.total` on `/jobs`.
- **Sparse fields:** `_fields=id,title,link` on the content API. Use it — a full post object is 28 properties of rendered HTML.
- **Embedding:** `_embed` inlines author, featured media and terms, avoiding N+1 requests.
- **Schema discovery:** HTTP OPTIONS on any content collection returns that resource's full JSON Schema.
- **Errors:** NOT RFC 9457. WordPress returns `{"code","message","data":{"status"}}`; Greenhouse returns `{"error"}`.
- **Idempotency:** not supported on either surface. No public write path exists.
- **Rate limits:** none published, no rate-limit headers. robots.txt asks for `Crawl-delay: 10` — treat that as the pacing contract.
- **Caching:** content collections are `Cache-Control: max-age=600` behind WP Engine and Cloudflare.
- **Indexing:** API responses carry `x-robots-tag: noindex`. Public, but deliberately not indexed.

## Agent posture

- No MCP server. No A2A agent card at either `/.well-known/agent-card.json` or `/.well-known/agent.json` (both 404).
- No `/.well-known/security.txt`, `openid-configuration`, `oauth-authorization-server`, `api-catalog` or `ai-plugin.json` (all 404).
- The WordPress Abilities API (`wp-abilities/v1`) IS registered on the host — a native agent-capability registry — but returns `401 rest_forbidden` anonymously. It is the one unrealised agent surface here.
- `robots.txt` disallows nothing: `User-agent: * / Disallow:`. All agents are permitted.
- Candidate MCP tools derived from these specs: [mcp/lifemine-mcp.yml](https://raw.githubusercontent.com/api-evangelist/lifemine/refs/heads/main/mcp/lifemine-mcp.yml) — candidate only, not deployed by LifeMine.
- Packaged agent skills: [skills/](https://github.com/api-evangelist/lifemine/tree/main/skills) — track company news, map leadership and board, monitor open roles.
